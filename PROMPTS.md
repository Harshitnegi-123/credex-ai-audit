# AI Prompt Examples

## Downgrade Recommendation Prompt

Analyze the following AI subscription setup and explain whether the team is overspending on unused collaboration features.

Inputs:
- Tool Name
- Current Plan
- Team Size
- Monthly Spend

Expected Output:
A concise recommendation explaining potential savings and optimization opportunities.

---

## Upgrade Recommendation Prompt

Analyze whether a growing team would benefit from premium collaboration and administrative features.

Inputs:
- Team Size
- Current Plan
- Recommended Plan

Expected Output:
A short explanation describing scalability and collaboration benefits.

---

## Optimized Setup Prompt

Determine whether the current AI subscription setup already appears cost-efficient.

Expected Output:
A concise validation summary confirming efficient usage.
