# Reflection

This project helped improve understanding of:

- Fullstack architecture
- API integration
- React state management
- Backend business logic
- Dynamic rendering
- Debugging workflow
- Clean project structuring

Key learning:
Building the core business logic first is more important than overbuilding authentication or database systems early.

A major improvement during development was transitioning from hardcoded recommendation logic to a scalable configuration-driven audit engine using reusable pricing and rule objects.
